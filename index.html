Joke Generator

  • Apply XHR in a practical application.
  • Decide when and why a request should be made.
  • Handle successful and unsuccessful requests appropriately.
  • Extract useful information from the response.
  • Display the joke in the webpage.
  • Focus on integrating several pieces into a working application.

The project will be approached following these stages:

  1. Define the requirements

    2. Establish what the Joke Generator should do from the user's perspective.

  2. Understand the API

    3. Identify a suitable joke API, its endpoint, the response format and whether it permits browser requests.

  3. Plan the application

    4. Decide what the user interface needs, what triggers the request and how the response will be displayed.

  4. Write pseudocode

    5. Describe the application logic in plain English. We will review it before you write JavaScript.

  5. Implement and test

    6. Build the application incrementally, test successful responses and investigate failures.

  6. Review the result

    7. Evaluate whether the application works reliably and whether the code is understandable and maintainable.
